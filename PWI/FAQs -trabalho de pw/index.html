C#

O que é C#?

É uma linguagem de programação multiparadigma usada para criar praticamente qualquer tipo de software.

para que serve o C#?

É uma linguagem de programação multiparadigma usada para criar praticamente qualquer tipo de software. É muito utilizada para desenvolver sistemas web (APIs e sites), aplicações mobile (via .NET MAUI), jogos (com a engine Unity) e sistemas de grande porte em ambientes corporativos.

O C# é uma linguagem compilada. O que isso significa?

A linguagem compilada é traduzida em código de máquina antes de ser executada pelo computador. O código fonte é escrito em uma linguagem de programação de alto nível e depois é processado por um compilador que transforma o código fonte em código de máquina, que é executado diretamente pelo hardware.

O que é uma classe em C#?

Uma classe em C# é um modelo usado para definir objetos. Ela especifica o que um objeto pode fazer, incluindo as suas propriedades, comportamento e relacionamentos com outros objetos.

Qual a diferença entre tipos de valor e tipos de referência em C#?

Os dois são variáveis, mas os tipos de valor contêm os próprios dados, mantendo-os na sua alocação de memória. Já os tipos de referência apontam para outro local de memória que possuem os dados reais. O local de armazenagem também é diferente. Os tipos de valor ficam na stack, e os tipos de referência ficam na heap.

CSS

O que é CSS?

CSS é a linguagem que cuida da aparência de uma página web.

O que significa CSS?

É a sigla para Cascading Style Sheets (Folhas de Estilo em Cascada). O termo "Cascada" refere-se à ordem de prioridade que o navegador utiliza para aplicar estilos quando há múltiplos conflitos de regras.

Quais são as principais formas de adicionar CSS?

As três principais formas de adicionar CSS a uma página HTML são: Externo, Interno e Inline.

Como funciona a estrutura básica de uma regra CSS?

O código é formado por um Seletor (que escolhe o elemento HTML que você quer estilizar) e um bloco de Declaração (que define as regras).

quais as vantagens de usar css?

Separação entre Conteúdo e Design, Manutenção mais Fácil, Reutilização de Código, Sites Responsivos, Carregamento Mais Rápido, Compatibilidade e Padronização.

Javascript

O que é Javascript?

é uma linguagem de programação de alto nível usada principalmente para criar interatividade, dinamismo e comportamento inteligente em páginas da web e aplicativos.

O que o Javascript consegue fazer?

adicionar interatividade, dinamismo e lógica a aplicações.

Javascript funciona apenas no navegador?

Não. O JavaScript não funciona apenas no navegador. Embora ele tenha sido criado originalmente para rodar em browsers (como Chrome, Safari e Firefox), hoje a linguagem é usada em praticamente qualquer lugar, do servidor aos dispositivos móveis.

Onde o JavaScript é Utilizado?

Front-end, Back-end, Aplicativos Mobile e desenvolvimento de Jogos.

O que acontece se um site ficar sem o Javascript?

Se um site ficar sem JavaScript, ele perde sua interatividade e dinamismo. O comportamento exato depende de como o site foi programado, podendo variar desde a perda de pequenos detalhes estéticos até a página ficar completamente em branco e inutilizável.

Java

O que é Java?

O que o Java consegue fazer?

Ele consegue criar desde pequenos aplicativos até sistemas de grande porte.

Java funciona apenas no navegador?

Não. Na verdade, a maior parte das aplicações Java não roda no navegador.

Onde o Java é Utilizado?

Ele está presente desde o sistema operacional do seu celular até em servidores de grandes corporações.

Por que o Java é importante?

O Java é importante por ser uma linguagem de programação orientada a objetos, amplamente utilizada em aplicações empresariais, desenvolvimento web, mobile e desktop. Sua portabilidade e robustez o tornam uma escolha popular para o desenvolvimento de software.

PHP

O que é PHP?

é uma linguagem de programação de código aberto voltada principalmente para a criação de aplicações e sites dinâmicos na web.

para que serve o PHP?

Qualquer coisa. O PHP é focado principalmente nos scripts do lado do servidor, portanto ele pode fazer qualquer coisa que qualquer outro programa CGI pode fazer, como coletar dados de formulários, gerar páginas com conteúdo dinâmico ou enviar e receber cookies. Mas o PHP pode fazer muito mais.

O PHP funciona apenas no navegador?

Não. Na verdade, o PHP nunca roda diretamente no navegador.

O que é uma classe em PHP?

Uma classe em PHP é um molde ou modelo que define as características (atributos) e os comportamentos (métodos) que um objeto terá.

Qual a diferença entre tipos de valor e tipos de referência em PHP?

No PHP, a principal diferença é que tipos de valor armazenam os dados diretamente na variável, e qualquer alteração cria uma cópia. Tipos de referência armazenam um identificador que aponta para um mesmo local na memória, portanto, alterações em uma variável afetam todas as outras ligadas a ela.

SQL

O que é SQL?

É a linguagem de programação padrão utilizada para gerenciar, consultar e manipular dados em bancos de dados relacionais.

Quais são os 3 tipos de dados SQL?

Os três principais tipos de dados no SQL são classificados de acordo com a natureza da informação armazenada: Numéricos, Texto (String) e Data/Hora (Temporais).

Quando ele foi desenvolvido?

O SQL foi desenvolvido originalmente no início dos anos 70 nos laboratórios da IBM em San Jose, dentro do projeto System R, que tinha por objetivo demonstrar a viabilidade da implementação do modelo relacional proposto por E. F. Codd.

O que é uma query em SQL?

Uma query SQL (ou consulta) é um conjunto de instruções enviado a um banco de dados para realizar ações como buscar, inserir, atualizar ou excluir informações

Qual a diferença entre tipos de valor e tipos de referência em SQL?

Em bancos de dados relacionais, a distinção entre "tipos de valor" e "tipos de referência" não funciona da mesma forma que em linguagens de programação orientadas a objetos (como C# ou Java). No SQL, todos os tipos de dados armazenam valores literais.

TypeScript

O que é o TypeScript?

O TypeScript é um superconjunto de código aberto do JavaScript desenvolvido pela Microsoft.

para que serve o TypeScript?

Ele serve para adicionar tipagem estática ao código, permitindo identificar erros durante o desenvolvimento (antes de o sistema ir para o ar) e facilitando a manutenção de aplicações grandes e complexas.

TypeScript substitui o JavaScript?

Não, o TypeScript não substitui o JavaScript. Ele é um superconjunto (superset) do JavaScript, o que significa que todo código JavaScript válido é também um código TypeScript válido, mas o navegador não consegue ler o TypeScript diretamente sem antes convertê-lo.

O que é uma classe em TypeScript?

é um molde ou modelo estrutural usado para criar objetos.

Qual a diferença entre tipos de valor e tipos de referência em TypeScript?

a distinção principal não está em declarar a variável em si, mas sim em como o dado é armazenado na memória e como ele se comporta ao ser copiado ou passado para funções.
